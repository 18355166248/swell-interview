## 核验与纠偏

每题 sources 指向本次读取的 MDN、React、Next.js、Node.js 或 web.dev 资料；来源失效路径已换到实际可访问的官方页面。答案为项目自行归纳，不搬运原帖标准答案。

- Hook 顶层规则明确限定 useState/useEffect 等，React 19 use 的条件调用单独说明。
- Promise/await 不自动提供线程并行或底层取消；并发拒绝要及时接入处理链。
- promisify 教学代码只支持 error-first 单值回调，保留 this、同步抛错及首次敲定语义；不冒充 Node 完整实现。
- 数组反转示例限定稠密可写数组；原生 reverse 保留空槽，与简单交换赋值不同。
- 深拷贝区分 JSON、structuredClone 和手写输入域，不承诺保留函数、自定义原型与描述符。
- CSS 冲突先看层叠来源/重要性/层，再看特异性，不按 class 属性顺序决胜。
- Next.js Client Component 不等于首次加载只在浏览器渲染；可序列化 props 不等同仅 JSON，也不允许泄露服务端秘密。
