## 核验与纠偏

答案由项目整理，以每题 sources 中的官方文档、规范或官方仓库为依据；不是照搬帖子里的回答，也不是该公司认可的标准答案。场景题写明前提与权衡，教学代码说明不支持范围。review.status=verified 表示本次编辑已做资料核对，不表示自动证明全部正确。

- Core Web Vitals 使用 LCP/INP/CLS，未把历史 TTI/FID 当当前三项核心指标。
- storage 不通知发起变更的当前窗口；sessionStorage 不当作跨独立标签页广播。
- TLS 1.3 不用旧式 RSA 密钥传输描述。
- 401 单飞方案有协议、迟到响应、取消和幂等写入前提；不是客户端万能重试。
- SSE 的网络块、UTF-8 字符、行、事件分界分开处理。
- Markdown 表格不使用“一个换行证明完整”的伪规则；原始 HTML 仍需安全处理。
- 浏览器/Node 事件循环、React/Vue key 不混成完全相同语义。
- 构造示例用 Reflect.construct，未宣称普通 apply 模拟支持所有 class/内建构造器。
