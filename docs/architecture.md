# 首期方案与实现边界

确认方案：专题学习手册布局，蓝紫主色，学习、收藏、复习、设置四入口；桌面侧栏、手机底部导航与专题抽屉。用户明确要求优先使用完整组件库，因此选用 Mantine 与其 code-highlight、notifications 扩展；不实现自有基础控件。

参考 douyu-desktop 的 React/TypeScript 和桌面运行边界，独立建立当前项目，没有复制直播、登录、协议、IPC 或播放器逻辑。Web 由 Vite 生成 dist/client；Electron 主进程只加载本地资源和打开 HTTPS 资料外链；Capacitor 加载同一产物。

本机数据采用带版本的 localStorage，并校验读取结构。版本或数据不合法时保留旧值，提示本次仅会话内可用。后续跨端同步需要账户、服务端协议、冲突处理和迁移设计，当前没有假设这些能力已存在。

复习队列在开始一轮时固定，避免自评后数据集变化导致跳题。收藏练习可以包含已掌握题；普通复习只选择 review 题。结果页区分已自评与跳过，不把查看答案视为掌握。

前期不引入服务端、重量状态管理、题目编辑器和通用插件机制。后续优先补充带出处的前端题目、版本复核和真机验收，再评估间隔复习和云同步。
